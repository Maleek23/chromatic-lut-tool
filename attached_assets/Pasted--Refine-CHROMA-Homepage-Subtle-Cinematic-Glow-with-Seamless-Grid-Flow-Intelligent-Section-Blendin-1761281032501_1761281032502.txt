"Refine CHROMA Homepage: Subtle Cinematic Glow with Seamless Grid Flow & Intelligent Section Blending"

Prompt Body:
You are a senior motion designer refining the CHROMA homepage to achieve a sophisticated, cinema-grade aesthetic. The current design has a glowing grid effect that's too intense and creates harsh visual boundaries between sections. Your task is to create a subtle, flowing glow system that feels organic, seamless, and professional.

🎯 Design Objectives
Problems to Solve:

Glow is too bright/harsh

Current state: Aggressive cyan/magenta glow overwhelms content
Desired state: Subtle, atmospheric glow that enhances without distracting


Grid doesn't flow into header/footer

Current state: Grid stops abruptly at section boundaries
Desired state: Grid extends naturally into header/footer with fade


Section transitions feel cut/disconnected

Current state: Visible "lines" between hero, content blocks, footer
Desired state: Seamless gradient blending as user scrolls


Glow feels static/artificial

Current state: Fixed glow doesn't respond to scroll or content
Desired state: Dynamic glow that flows with user interaction

3. Scroll-Reactive Glow Blending
Dynamic Glow Transitions:
javascript// Glow adapts to scroll position
class ScrollReactiveGlow {
  constructor() {
    this.glowElement = document.querySelector('.hero-glow');
    this.heroSection = document.querySelector('.hero-section');
    this.contentSections = document.querySelectorAll('.content-section');
    
    this.setupScrollListener();
  }
  
  setupScrollListener() {
    let ticking = false;
    
    window.addEventListener('scroll', () => {
      if (!ticking) {
        window.requestAnimationFrame(() => {
          this.updateGlow();
          ticking = false;
        });
        ticking = true;
      }
    });
  }
  
  updateGlow() {
    const scrollY = window.scrollY;
    const heroHeight = this.heroSection.offsetHeight;
    const scrollPercent = Math.min(scrollY / heroHeight, 1);
    
    // Fade glow as user scrolls down
    const glowOpacity = 0.6 - (scrollPercent * 0.4); // 0.6 → 0.2
    const glowBlur = 60 + (scrollPercent * 40);      // 60px → 100px
    const glowScale = 1 + (scrollPercent * 0.3);     // 1 → 1.3
    
    this.glowElement.style.opacity = glowOpacity;
    this.glowElement.style.filter = `blur(${glowBlur}px)`;
    this.glowElement.style.transform = `scale(${glowScale})`;
    
    // Transition glow color as user enters content sections
    this.updateGlowColor(scrollY);
  }
  
  updateGlowColor(scrollY) {
    this.contentSections.forEach((section, index) => {
      const sectionTop = section.offsetTop;
      const sectionHeight = section.offsetHeight;
      const sectionBottom = sectionTop + sectionHeight;
      
      // Check if scroll is within section
      if (scrollY >= sectionTop - 200 && scrollY <= sectionBottom) {
        // Blend glow color with section's accent color
        const sectionColor = getComputedStyle(section)
          .getPropertyValue('--accent-color') || 'rgba(99, 102, 241, 0.12)';
        
        this.glowElement.style.boxShadow = `
          0 0 150px ${sectionColor},
          0 0 80px rgba(139, 92, 246, 0.12),
          0 0 40px rgba(236, 72, 153, 0.08)
        `;
      }
    });
  }
}

// Initialize
new ScrollReactiveGlow();

Scroll-Triggered Glow Pulse:
javascript// Pulse glow when user reaches key sections
const observerOptions = {
  threshold: 0.3,
  rootMargin: '-100px'
};

const glowPulseObserver = new IntersectionObserver((entries) => {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
      // Subtle pulse when section enters view
      document.querySelector('.hero-glow').style.animation = 
        'glow-pulse 1.5s ease-out';
      
      setTimeout(() => {
        document.querySelector('.hero-glow').style.animation = 
          'glow-breathe 8s ease-in-out infinite';
      }, 1500);
    }
  });
}, observerOptions);

// Observe key sections
document.querySelectorAll('.content-section').forEach(section => {
  glowPulseObserver.observe(section);
});
