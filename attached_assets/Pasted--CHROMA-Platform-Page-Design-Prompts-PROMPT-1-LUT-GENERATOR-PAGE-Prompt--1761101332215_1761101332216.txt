## 📄 **PROMPT 1: LUT GENERATOR PAGE**

### **Prompt Title:**
**"Design a Professional LUT Generator Interface with Real-Time Cinema-Grade Preview & Precise Color Control"**

---

### **Prompt Body:**

You are a senior product designer creating the flagship tool interface for **CHROMA**, a professional color science platform. Design the **Image to LUT Generator** page where colorists and filmmakers extract authentic color grading from reference images using cinema-grade chroma science.

The page must balance professional precision with visual elegance, showcasing the technical sophistication while remaining intuitive for both expert colorists and ambitious creators.

---

### 🎯 **Page Objectives**

**Primary Goal:** Enable users to generate production-ready 3D LUTs from reference images in <2 minutes

**User Flow:**
1. Upload reference image (drag-drop or browse)
2. Preview LUT applied to reference in real-time
3. Adjust intensity, grid size, precision, format
4. Generate & download LUT with comprehensive metadata

**Success Metrics:**
- Time to first LUT: <90 seconds
- Clarity of technical controls: No tooltip reliance for basic flow
- Preview accuracy: Represents final output exactly
- Error prevention: Invalid settings caught before generation

---
