# 🎨 CHROMA Dashboard Design Prompt

---

## **Prompt Title:**
**"Design a Professional Color Grading Dashboard with Real-Time Usage Analytics, Live Preview System & Intelligent Project Management"**

---

## **Prompt Body:**

You are a senior product designer creating the **Dashboard** for **CHROMA**, a professional color science platform. This is the central command center where colorists manage their LUT library, monitor usage, access quick tools, and track their color grading workflow.

The dashboard must balance quick-access functionality (generate LUTs fast) with project management depth (organize, analyze, reuse), all while maintaining the cinema-grade aesthetic that defines CHROMA's brand.

---

## 🎯 **Dashboard Objectives**

**Primary Goals:**
1. **Speed:** Generate new LUT in <30 seconds from dashboard
2. **Organization:** Quick access to recent LUTs and projects
3. **Insights:** Usage analytics and tier limitations visibility
4. **Discovery:** Surface pro features without annoying free users

**User Personas:**
- **Free Tier:** Wants fast LUT generation, clear upgrade value
- **Creator Tier:** Manages multiple projects, needs organization
- **Pro Tier:** Power user, wants analytics and advanced tools

## 🎯 **Design Principles**

### **1. Dashboard is Control Center, Not Gallery**
- Prioritize actions over aesthetics
- Show data, not decorations
- Every element has purpose

### **2. Respect User's Time**
- Fast access to recent work
- No unnecessary clicks
- Clear paths to common tasks

### **3. Transparent Limitations**
- Show usage clearly (not hidden in settings)
- Explain tier restrictions (not just "locked")
- Upgrade prompts educational, not annoying

### **4. Professional, Not Playful**
- Serious tool for serious work
- Data-driven design language
- Cinema-grade aesthetic throughout

---

**Final Note:** The dashboard is the user's home base. It should feel like a professional workstation—organized, efficient, and powerful. Every returning user should immediately know their status, access their work, and start creating. This is mission control for color grading. 🎬✨
