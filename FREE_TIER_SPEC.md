# FREE TIER - Official Specification
**Last Updated:** January 20, 2025

## Pricing
- **Cost:** $0/forever
- **Monthly Limit:** 3 Image-to-LUT generations
- **Resets:** 1st of each month
- **Pay-per-use:** $2.50 per additional LUT after monthly limit

## Image-to-LUT Generation
- **Monthly Quota:** 3 free generations
- **Grid Size:** 17×17×17 only (Preview quality)
- **Output Format:** .cube only
- **File Size Limit:** 10MB
- **Supported Input Formats:** JPG, JPEG, PNG, WEBP, HEIC, HEIF, TIFF, TIF, BMP, GIF

## LUT Conversion
- **Source Formats:** Can convert FROM .cube, .3dl, .lut, .look
- **Destination Formats:** Can convert TO .cube ONLY
- **Grid Resampling:** To 17×17×17 only
